💡 EXTRACTION LOGIC (SIMPLE & CORRECT)
═══════════════════════════════════════════════════════════════════

1. Split description by space → array of words
2. Check dari BELAKANG → find last word dengan angka
3. Customer name = ALL CAPS words SETELAH word tsb

Example 1:
  Description : Z1AL1 ANDRE ISKANDAR
  Words       : ['Z1AL1', 'ANDRE', 'ISKANDAR']
  Last number : index 0 (Z1AL1)
  Result      : ANDRE ISKANDAR ✅

Example 2:
  Description : WS95051 911040.00 CAFE RSPI SARI PUSPITA PT
  Words       : ['WS95051', '911040.00', 'CAFE', ...]
  Last number : index 1 (911040.00)
  Result      : CAFE RSPI SARI PUSPITA PT ✅
