✨ WHAT'S NEW:


1️⃣ MINIMAL TRANSAKSI: 2 → 1
═══════════════════════════════════════════════════════════════════

   SEBELUM: BTP harus punya minimal 2 transaksi
   SEKARANG: BTP dengan 1 transaksi pun bisa masuk!
   
   Impact:
   ✅ Full coverage - semua BTP dengan customer name akan masuk
   ✅ Tidak ada BTP yang terlewat karena transaksi sedikit
   ✅ User bisa lihat semua kemungkinan


2️⃣ PARTIAL MATCHING (Character-Level)
═══════════════════════════════════════════════════════════════════

   Fitur BARU untuk handle nama terpotong!
   
   Contoh Case:
   Di CSV    : "KOKUMINDO BERKAT M" (terpotong)
   Di Master : "KOKUMINDO BERKAT MANDIRI"
   
   SEBELUM: ❌ NO MATCH (exact match required)
   SEKARANG: ✅ MATCH! (80%+ character similarity)
   
   How it Works:
   • Hitung similarity per karakter
   • Jika ≥80% similarity → MATCH
   • Minimal 10 karakter untuk partial match
   • Exact match tetap prioritas #1
   
   Impact:
   ✅ Handle nama terpotong
   ✅ Handle typo minor
   ✅ Increase coverage ~10-20%

⚙️ TECHNICAL DETAILS
═══════════════════════════════════════════════════════════════════

Partial Matching Algorithm:
────────────────────────────────────────────────────────────────
• Check substring containment
• Calculate: (min_length / max_length) × 100%
• If ≥80% → Consider as match
• Minimal 10 characters for partial match
• Exact match always prioritized

Example:
  Pattern: "KOKUMINDO BERKAT MANDIRI" (24 chars)
  Input  : "KOKUMINDO BERKAT M" (18 chars)
  
  Similarity: (18 / 24) × 100% = 75%
  Result: ❌ Not enough (need ≥80%)
  
  BUT if substring:
  Input contains "KOKUMINDO BERKAT M" (18 chars)
  Pattern contains "KOKUMINDO BERKAT M" → substring match!
  Result: ✅ MATCH (substring detected)


Multiple Results Logic:
────────────────────────────────────────────────────────────────
1. Find ALL patterns that match (exact or partial)
2. Sort by:
   a. Similarity (100% first, then 99%, 98%, etc)
   b. Name length (longer = more specific)
   c. Match percentage
3. Return top 3-5 results
4. Display all to user


Warning System:
────────────────────────────────────────────────────────────────
• <50%  : 🔴 Excluded from master
• 50-69%: 🔴 LOW - don't include
• 70-79%: 🟠 FAIR - show warning
• 80-89%: 🟡 GOOD - show caution
• 90-94%: 🔵 VERY GOOD
• ≥95%  : 🟢 EXCELLENT
