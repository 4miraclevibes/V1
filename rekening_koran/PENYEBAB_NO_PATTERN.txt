JAWABAN SINGKAT: KENAPA BTP BISA NO PATTERN?
═══════════════════════════════════════════════════════════════════


Berdasarkan investigation 3 BTP dari testing Anda:


1️⃣ NAMA CUSTOMER TERPOTONG (Paling Sering!) 🏆
═══════════════════════════════════════════════════════════════════

   Contoh: BTP 2300007505
   
   Di CSV    : "KOKUMINDO BERKAT M" (terpotong!)
   Di Master : "KOKUMINDO BERKAT MANDIRI" (nama lengkap)
   
   → Matching gagal karena nama tidak exact sama
   → Padahal customer konsisten 100%!
   
   Impact: ~30-40% dari NO PATTERN


2️⃣ NOMOR INVOICE MASUK KE CUSTOMER NAME 💥
═══════════════════════════════════════════════════════════════════

   Contoh: BTP 2300014763
   
   Transaksi 1: "N7159289 DAVID TANTRIS OR F"
   Transaksi 2: "N7148815 DAVID TANTRIS OR F"
   Transaksi 3: "K002000027001 DAVID TANTRIS OR F"
   
   → Program detect 40 customer berbeda (padahal sama!)
   → Customer dominan cuma 71.3% (< threshold 80%)
   → Tidak masuk master
   
   Impact: ~20-30% dari NO PATTERN


3️⃣ VARIASI PENULISAN
═══════════════════════════════════════════════════════════════════

   Contoh: BTP 2300010747
   
   Transaksi 1: "NG SIOE HOH"
   Transaksi 2: "N7026502 NG SIOE HOH"
   
   → Detected sebagai 2 customer berbeda
   → Masing-masing 50% (tidak ada yang >= 80%)
   
   Impact: ~10-15% dari NO PATTERN


4️⃣ TRANSAKSI < 2 (Normal) ✅
═══════════════════════════════════════════════════════════════════

   → BTP jarang dipakai
   → Tidak reliable untuk pattern
   
   Impact: ~10-15% dari NO PATTERN


5️⃣ TIDAK ADA CUSTOMER NAME (Normal) ✅
═══════════════════════════════════════════════════════════════════

   → Format lama atau tidak lengkap
   
   Impact: ~5-10% dari NO PATTERN


═══════════════════════════════════════════════════════════════════
💡 SOLUSI CEPAT
═══════════════════════════════════════════════════════════════════

✅ Untuk Nama Terpotong:
   → Cari nama lengkap di raw data
   → Add alias di master (nama pendek + nama panjang)

✅ Untuk Invoice Number Issue:
   → Update pattern extraction
   → Strip pattern seperti: N[0-9]{7}, K00[0-9]+

✅ Untuk Variasi:
   → Data cleansing
   → Standardize format
