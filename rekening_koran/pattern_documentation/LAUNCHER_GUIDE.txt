================================================================================
🚀 BANK PATTERN GENERATOR LAUNCHER - USER GUIDE
================================================================================

OVERVIEW
--------
Pattern Launcher adalah command center untuk menjalankan dan mengelola semua
20 bank pattern generators dari satu tempat.

Dengan launcher ini, Anda bisa:
✅ Test BTP patterns untuk bank manapun
✅ Generate/regenerate patterns untuk bank tertentu
✅ Lihat daftar semua bank yang tersedia
✅ Akses dokumentasi lengkap

================================================================================
INSTALLATION & COMPILATION
================================================================================

STEP 1: Compile the Launcher
-----------------------------
cd /Users/balian/Documents/GitHub/V1/rekening_koran/pattern_documentation
gcc pattern_launcher.c -o pattern_launcher

STEP 2: Make it Executable (Optional)
--------------------------------------
chmod +x pattern_launcher

STEP 3: Run the Launcher
-------------------------
./pattern_launcher

================================================================================
MENU OPTIONS
================================================================================

1. 🔍 Test BTP Pattern (Select Bank)
   ------------------------------------
   - Menampilkan daftar semua 20 banks
   - Pilih bank yang ingin di-test
   - Launcher akan menjalankan test_btp_pattern untuk bank tersebut
   - Anda bisa manual input description untuk dicari BTP-nya
   
   Contoh workflow:
   1) Pilih menu 1
   2) Pilih bank (misal: 3 untuk MANDIRI)
   3) Program test akan berjalan
   4) Masukkan description untuk dicari BTP-nya
   5) Lihat hasil matching

2. 📊 Show All Banks
   ------------------
   - Menampilkan daftar lengkap 20 banks
   - Dikelompokkan berdasarkan extraction logic:
     • Group 1: Array[3]+[4] (9 banks)
     • Group 2: Array[4]+[5] (9 banks)
     • Group 3: Special Logic (2 banks)
   - Menunjukkan ID dan nama setiap bank

3. 🔧 Generate Patterns (Select Bank)
   ------------------------------------
   - Regenerate patterns untuk bank tertentu
   - Ada konfirmasi sebelum execute (untuk avoid accident)
   - Launcher akan menjalankan generate_patterns untuk bank tersebut
   - Hasil: master_customer_btp_pattern_[BANK].sql akan di-update
   
   ⚠️  WARNING: Ini akan overwrite file SQL yang sudah ada!
   
   Contoh workflow:
   1) Pilih menu 3
   2) Pilih bank (misal: 10 untuk CIMB)
   3) Konfirmasi dengan 'y'
   4) Generator akan berjalan
   5) Check hasil di folder bank tersebut

4. 📖 Show Documentation
   ----------------------
   - Menampilkan 100 baris pertama dari documentation.txt
   - Overview lengkap tentang semua pattern generators
   - Info extraction logic untuk setiap group
   - Statistics dan feature list

Q. ❌ Quit
   -------
   - Keluar dari launcher

================================================================================
TROUBLESHOOTING
================================================================================

Problem: "Executable not found"
Solution:
  Launcher akan memberitahu jika executable belum di-compile.
  Ikuti instruksi yang muncul untuk compile terlebih dahulu.
  
  Example:
  cd ../pattern_generator_MANDIRI
  gcc test_btp_pattern.c -o test_btp_pattern_mandiri

Problem: "Permission denied"
Solution:
  chmod +x pattern_launcher
  atau run dengan: ./pattern_launcher

Problem: Program tidak bisa kembali ke menu
Solution:
  Tekan Enter untuk continue setelah selesai menjalankan test/generator

Problem: Clear screen tidak berfungsi
Solution:
  Ini normal di beberapa terminal. Program tetap berjalan dengan baik.

PREREQUISITES
================================================================================

Before using the launcher, pastikan:
✅ All pattern generators sudah di-compile
✅ CSV files tersedia di setiap folder bank
✅ Anda berada di folder pattern_documentation saat run launcher

Quick compile all (opsional):
------------------------------
for dir in ../pattern_generator_*/; do
  cd "$dir"
  gcc generate_patterns.c -o generate_patterns_* 2>/dev/null
  gcc test_btp_pattern.c -o test_btp_pattern_* 2>/dev/null
  cd -
done

================================================================================
TIPS & TRICKS
================================================================================

💡 Tip 1: Quick Testing
   Gunakan launcher untuk quick test berbagai bank tanpa perlu cd ke folder
   masing-masing.

💡 Tip 2: Batch Testing
   Bisa test multiple banks secara berurutan tanpa keluar dari launcher.

💡 Tip 3: Safe Regeneration
   Menu 3 punya konfirmasi, jadi aman dari accidental regeneration.

💡 Tip 4: Documentation Access
   Menu 4 untuk quick reference tanpa perlu buka file manual.

💡 Tip 5: Navigation
   Gunakan angka 1-4 untuk menu utama
   Gunakan angka 1-20 untuk pilih bank
   Gunakan Q untuk quit

================================================================================
UPDATES & MAINTENANCE
================================================================================

Adding New Bank:
----------------
1. Edit pattern_launcher.c
2. Add new bank to banks[] array
3. Recompile: gcc pattern_launcher.c -o pattern_launcher

Updating Executable Names:
--------------------------
If you change executable naming convention:
1. Update banks[] array in pattern_launcher.c
2. Recompile
