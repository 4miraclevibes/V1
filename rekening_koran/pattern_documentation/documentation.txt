🔍 EXTRACTION LOGIC DETAILS
================================================================================

GROUP 1: Array[3] + Array[4] (Smart PT/CV)
-------------------------------------------
Format: "KR OTOMATIS LLG-[BANK] [WORD1] [WORD2] [WORD3]..."
Extraction:
  • Array[3] + Array[4] (default: 2 words)
  • If Array[3] = "PT" or "CV" → Array[3] + Array[4] + Array[5] (3 words)

Example:
  "KR OTOMATIS LLG-BRI PT MITRA SELERA GREENFIELDS"
   [0]    [1]    [2]  [3] [4]    [5]      [6]
  Result: "PT MITRA SELERA" (3 words because Array[3] = "PT")

Banks: BNI, BTPN, MANDIRI, BRI, MEGA, PERMATA, DANAMON, CITIBANK, SINARMAS

GROUP 2: Array[4] + Array[5] (Smart PT/CV)
-------------------------------------------
Format: "KR OTOMATIS LLG-[BANK] [SPECIAL] [WORD1] [WORD2] [WORD3]..."
Extraction:
  • Array[4] + Array[5] (default: 2 words)
  • If Array[4] = "PT" or "CV" → Array[4] + Array[5] + Array[6] (3 words)
  • Special word at Array[3] (NIAGA/INDONE/INDONESIA/INDON/NISP)

Example:
  "KR OTOMATIS LLG-CIMB NIAGA PT RUANG MAHA KARYA"
   [0]    [1]     [2]   [3]  [4] [5]   [6]   [7]
  Array[3] = "NIAGA" (skip)
  Result: "PT RUANG MAHA" (3 words because Array[4] = "PT")

Banks: CIMB, MAYBANK, HSBC, UOB, MUAMALAT, OCBC, DBS, CAPITAL, WOORI

GROUP 3: Special Logic - TRSF & BI-FAST
----------------------------------------
Format: Dynamic extraction based on ALL CAPS words
Extraction:
  • Find last number in description
  • Extract ALL CAPS words after that number
  • Filter out month prefixes (JAN, FEB, MAR, APR, MEI, JUN, etc.)
  • Minimum 2 characters, all uppercase

Example (TRSF):
  "TRSF E-BANKING CR 0201/FTSCY/WS95051 1822080.00 INV GLORIA PRIMA CV"
  Last number: 1822080.00
  ALL CAPS after: "INV", "GLORIA", "PRIMA", "CV"
  Result: "GLORIA PRIMA CV"

Example (BI-FAST):
  "BI-FAST CR TRANSFER DR 008 NOVA ANGGRAINI"
  Last number: 008
  ALL CAPS after: "NOVA", "ANGGRAINI"
  Result: "NOVA ANGGRAINI"

Banks: TRSF, BI-FAST

🚀 USAGE WORKFLOW
================================================================================

1. Compile Programs:
   cd pattern_generator_[BANK]
   gcc -o generate_patterns generate_patterns.c
   gcc -o test_btp_pattern test_btp_pattern.c

2. Generate Patterns:
   ./generate_patterns
   Output: master_customer_btp_pattern_[BANK].sql

3. Test Patterns:
   ./test_btp_pattern
   Menu:
   1. Manual Test - Test description untuk mendapatkan BTP
   2. Load Patterns - Reload patterns dari SQL
   3. Display All Patterns - Tampilkan semua patterns
   A. Daftar BTP - List BTPs grouped by BTP code
   B. BTP Terbaru - Latest BTPs by usage
   0. Exit

4. Use SQL Patterns:
   Import master_customer_btp_pattern_[BANK].sql ke database
   Query by customer name untuk mendapatkan recommended BTP
