CIMB PATTERN EXTRACTION LOGIC
==============================

Format Data CIMB:
- BTP;DESCRIPTION
- Description format: "KR OTOMATIS LLG-CIMB NIAGA [CUSTOMER_WORD1] [CUSTOMER_WORD2] [ADDITIONAL_INFO]"

Contoh:
- Input: "KR OTOMATIS LLG-CIMB NIAGA PT RUANG MAHA KARYA GREENFIELDS"
- Split by space: ["KR", "OTOMATIS", "LLG-CIMB", "NIAGA", "PT", "RUANG", "MAHA", "KARYA", "GREENFIELDS"]

EXTRACTION RULES:
================

1. BTP = Kolom pertama (sebelum semicolon)
2. Customer Name = Array[4] + Array[5] dengan SMART EXTRACTION
3. Pattern = Customer Name

SMART EXTRACTION LOGIC:
-----------------------
Jika Array[4] = "PT" ATAU Array[4] = "CV":
  → Customer Name = Array[4] + Array[5] + Array[6] (3 words)
  
Jika Array[4] bukan "PT" atau "CV":
  → Customer Name = Array[4] + Array[5] (2 words, default)

CONTOH EXTRACTION:
==================

Example 1 (dengan PT prefix):
- Input: "KR OTOMATIS LLG-CIMB NIAGA PT RUANG MAHA KARYA GREENFIELDS"
- Split: ["KR", "OTOMATIS", "LLG-CIMB", "NIAGA", "PT", "RUANG", "MAHA", "KARYA", "GREENFIELDS"]
- Array[4] = "PT"
- Array[5] = "RUANG"
- Array[6] = "MAHA"
- Smart Check: Array[4] = "PT" ✓
- Customer Name = "PT RUANG MAHA" (3 words)
- Pattern = "PT RUANG MAHA"

Example 2 (tanpa PT/CV):
- Input: "KR OTOMATIS LLG-CIMB NIAGA KOPERASI KARYAWAN GREENFIELDS INDONESIA"
- Split: ["KR", "OTOMATIS", "LLG-CIMB", "NIAGA", "KOPERASI", "KARYAWAN", "GREENFIELDS", "INDONESIA"]
- Array[4] = "KOPERASI"
- Array[5] = "KARYAWAN"
- Smart Check: Array[4] = "KOPERASI" (bukan PT/CV) ✗
- Customer Name = "KOPERASI KARYAWAN" (2 words)
- Pattern = "KOPERASI KARYAWAN"

Example 3 (dengan CV prefix):
- Input: "KR OTOMATIS LLG-CIMB NIAGA CV KARYA MANDIRI INDO BUKTI BAYAR"
- Split: ["KR", "OTOMATIS", "LLG-CIMB", "NIAGA", "CV", "KARYA", "MANDIRI", "INDO", "BUKTI", "BAYAR"]
- Array[4] = "CV"
- Array[5] = "KARYA"
- Array[6] = "MANDIRI"
- Smart Check: Array[4] = "CV" ✓
- Customer Name = "CV KARYA MANDIRI" (3 words)
- Pattern = "CV KARYA MANDIRI"

ALGORITHM:
==========

1. Split description by space
2. Check if array length >= 6 (minimal untuk array[4] dan array[5])
3. Extract array[4] dan array[5]
4. Smart Extraction Check:
   - If array[4] == "PT" OR array[4] == "CV":
     * Check if array[6] exists (array length >= 7)
     * If yes: customer_name = array[4] + " " + array[5] + " " + array[6]
     * If no: customer_name = array[4] + " " + array[5]
   - Else:
     * customer_name = array[4] + " " + array[5]
5. Pattern = Customer Name (sama dengan customer name untuk CIMB)

PERBEDAAN DENGAN BANK LAIN:
===========================

Banks menggunakan Array[3] + Array[4] (dengan smart PT/CV):
- BNI: Array[3] + Array[4], smart PT/CV
- BTPN: Array[3] + Array[4], smart PT/CV
- MANDIRI: Array[3] + Array[4], smart PT/CV
- BRI: Array[3] + Array[4], smart PT/CV
- MEGA: Array[3] + Array[4], smart PT/CV
- PERMATA: Array[3] + Array[4], smart PT/CV
- DANAMON: Array[3] + Array[4], smart PT/CV

Banks menggunakan Array[4] + Array[5] (dengan smart PT/CV):
- CIMB: Array[4] + Array[5], smart PT/CV ← INI
- MAYBANK: Array[4] + Array[5], smart PT/CV

Banks dengan logic khusus:
- TRSF: ALL CAPS words after last number

CATATAN PENTING:
===============

CIMB memiliki kata "NIAGA" di Array[3], sehingga extraction dimulai dari Array[4]:
- Array[0] = "KR"
- Array[1] = "OTOMATIS"
- Array[2] = "LLG-CIMB"
- Array[3] = "NIAGA" ← Kata khusus CIMB
- Array[4] = [WORD1] ← Extraction dimulai di sini
- Array[5] = [WORD2]
- Array[6] = [WORD3] (jika PT/CV)

VALIDATION:
===========

- Array length harus >= 6
- Array[4] dan Array[5] tidak boleh kosong
- Tidak ada filtering khusus (tidak seperti TRSF yang filter bulan)
- BTP bisa numeric atau non-numeric (e.g., "MODERN TRADE")
- Smart extraction otomatis handle PT/CV company names
