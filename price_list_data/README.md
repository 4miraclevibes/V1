# Price List Data

Folder ini berisi data price list yang dapat dibuka di Excel atau aplikasi spreadsheet lainnya.

## Files Available:

### 1. `price_list.csv`
- **Format**: Simple CSV dengan 3 kolom
- **Kolom**: NO, Item, Harga
- **Isi**: 23 items + total harga 581,070
- **Usage**: Import langsung ke Excel

### 2. `price_list_excel.csv`
- **Format**: Enhanced CSV dengan 6 kolom
- **Kolom**: NO, Item, Harga, Category, Size, Notes
- **Isi**: 23 items dengan detail kategori dan deskripsi
- **Usage**: Lebih detail untuk analisis

### 3. `price_summary.csv`
- **Format**: Summary by category
- **Kolom**: Category, Item Count, Total Price, Average Price
- **Isi**: Breakdown per kategori produk
- **Usage**: Analisis per kategori

## Categories:
- **ESL**: 7 items (229,130 total)
- **Jersey**: 1 item (41,090 total)
- **UHT**: 4 items (97,860 total)
- **Yogurt Drink**: 5 items (47,950 total)
- **Yogurt**: 6 items (136,350 total)

## Total: 581,070

## How to Use:
1. Buka file CSV di Excel
2. Data akan otomatis terformat sebagai tabel
3. Bisa langsung digunakan untuk analisis atau import ke database
4. Semua harga dalam format numerik (tanpa koma)

## Notes:
- File dibuat berdasarkan price list dari gambar
- Data siap pakai untuk Excel atau aplikasi spreadsheet
- Format CSV kompatibel dengan semua aplikasi spreadsheet
